## أسئلة للمراجعة القانونية
1. ما الأساس النظامي لنقل بيانات مقيمين في السعودية إلى الخوادم المختارة؟
2. هل يلزم تعيين مسؤول حماية بيانات أو عقود معتمدة؟
3. هل تحتاج المبادرة إلى ترخيص لجمع التبرعات؟
4. هل يجوز عرض الحسابات البنكية للزوار غير المسجّلين؟
