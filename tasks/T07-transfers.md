# T07 — رفع الحوالات والإيصالات

- **الفرع:** `task/T07-transfers`
- **يعتمد على:** T05, T02
- **المراجع:** `docs/SPEC.md` FR-13..17, §9 transfers, §12.6

## الهدف
رفع الإيصال يحتسب الحوالة فورًا، مع كشف المتكرر وحماية الملفات.

## المطلوب
1. migration `transfers` كما في §9 (`user_id`, `beneficiary_id`, `amount`, `transferred_on`, `receipt_path`, `receipt_hash`, `bank_reference`, `is_repeated`, `review_state`, `assigned_to`, `assigned_by`, `assigned_at`, `final_reviewed_by`, `final_reviewed_at`, `final_note`).
2. صفحة رفع: اختيار المستفيد من المتاحة فقط، المبلغ، التاريخ (لا يتجاوز اليوم)، الإيصال (JPG/PNG/PDF حتى 5MB).
3. التحقق من النوع الفعلي، وإعادة ترميز الصور وإزالة EXIF، وحفظ على قرص **خاص** بأسماء عشوائية، وتقديمه عبر مسار موقّع مؤقت مع Policy.
4. **تُحتسب فورًا**: لا حالة "قيد المراجعة" ولا "رفض".
5. خدمة كشف المتكرر: نفس `receipt_hash` أو `bank_reference`، أو نفس (المبادر، المستفيد، المبلغ، التاريخ) → `is_repeated = true` دون منع.
6. حد يومي لعدد الحوالات لكل مبادر (إعداد).
7. صفحة `/my-transfers`: **كل حوالات المبادر** (المستفيد، المبلغ، التاريخ، الإيصال).

## معايير القبول
- [ ] الحوالة تظهر في الإحصائيات مباشرة بعد الرفع.
- [ ] لا يستطيع مبادر عرض إيصال غيره.
- [ ] لا حوالات لمبادرة مغلقة أو غير معتمدة.
- [ ] لا EXIF في الملف المحفوظ.

## الاختبارات المطلوبة
- رفع ناجح، ملف بامتداد مزيَّف، تجاوز الحجم، تاريخ مستقبلي.
- كشف المتكرر بكل حالاته.
- 403 لإيصال الغير.
- الحد اليومي.
