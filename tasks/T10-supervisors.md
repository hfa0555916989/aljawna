# T10 — دعوة المشرفين وإدارتهم

- **الفرع:** `task/T10-supervisors`
- **يعتمد على:** T03, T04
- **المراجع:** `docs/SPEC.md` FR-19..21, §6 تدفق دعوة المشرف

## الهدف
دعوة مشرف برقم جواله برابط واتساب، وتسجيله لنفسه، وإدارة صلاحياته.

## المطلوب
1. جدول `supervisor_invites` (`phone`, `token_hash`, `permissions` json, `invited_by`, `expires_at` 72 ساعة, `accepted_at`).
2. صفحة (`supervisors.manage`): إدخال رقم المشرف (سعودي) مع قالب أو صلاحيات فردية → يولّد الخادم رمزًا عشوائيًا (32 بايت، مجزّأ) ويعيد رابط `wa.me` برسالة جاهزة تحمل رابط الانضمام.
3. `/join/{token}`: الرقم ثابت غير قابل للتعديل، الاسم الكامل (4 كلمات)، كلمة المرور وتأكيدها. يُستهلك الرمز.
4. إدارة المشرفين: تعديل الصلاحيات (بقواعد T03)، خيار `show_contact`، تعطيل/تفعيل، حذف. الحساب المعطّل لا يدخل.

## معايير القبول
- [ ] الرمز مجزّأ، لمرة واحدة، ينتهي بعد 72 ساعة.
- [ ] رابط `wa.me` صحيح الصيغة والترميز.
- [ ] لا يمكن لمشرف دعوة من يفوق صلاحياته.

## الاختبارات المطلوبة
- انتهاء الصلاحية وإعادة الاستخدام.
- صيغة `wa.me`.
- قواعد الصلاحيات عبر واجهة الإدارة.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
