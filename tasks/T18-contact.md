# T18 — اتصل بنا وصندوق الرسائل

- **الفرع:** `task/T18-contact`
- **يعتمد على:** T17
- **المراجع:** `docs/SPEC.md` FR-55

## الهدف
نموذج اتصل بنا اختياري بحماية سبام وصندوق رسائل للإدارة.

## المطلوب
1. كتلة "اتصل بنا": أزرار اتصال وواتساب (`tel:` و`wa.me`) ونموذج اختياري: الاسم، الجوال (سعودي)، الرسالة (حتى 1000 حرف).
2. Turnstile + honeypot + حد للمعدل لكل IP. جدول `contact_messages` كما في §9.
3. صندوق في Filament (`messages.view`): قائمة، وسم "مقروء"، وأزرار اتصال وواتساب للمرسِل.

## معايير القبول
- [ ] مسارات السبام مغلقة.
- [ ] الرسائل تظهر لمن يملك `messages.view` فقط.

## الاختبارات المطلوبة
- نجاح، حقل الفخ، حد المعدل، جوال غير سعودي، 403 للصندوق.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
