# T13 — إحصائيات الاستعادة

- **الفرع:** `task/T13-recovery-stats`
- **يعتمد على:** T12
- **المراجع:** `docs/SPEC.md` §4.4, FR-42

## الهدف
صفحة إحصائيات الاستعادة بالفترات، وقابلة للمنح.

## المطلوب
1. صفحة في Filament متاحة للمدير ولمن يملك `stats.recovery`.
2. مرشحات: يوم محدد، شهر، سنة، فترة مخصصة.
3. المؤشرات: الاستعادات المنجزة، الروابط الصادرة، تعديلات الأرقام، مع تفصيل حسب المشرف وحسب نوع الإجراء.
4. الحدود الزمنية بتوقيت `Asia/Riyadh`.

## معايير القبول
- [ ] الأرقام تطابق `recovery_log`.
- [ ] الحدود (بداية/نهاية اليوم والشهر والسنة) صحيحة.

## الاختبارات المطلوبة
- حالات الحدود ومنتصف الليل بتوقيت الرياض.
- 403 لمن لا يملك الصلاحية.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
