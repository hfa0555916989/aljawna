# T16 — وحدة الهوية (Branding)

- **الفرع:** `task/T16-branding`
- **يعتمد على:** T04
- **المراجع:** `docs/SPEC.md` FR-49, FR-56, §12.13

## الهدف
التحكم بالشعار والاسم والألوان من لوحة الإدارة بأمان.

## المطلوب
1. جدول `site_branding` وصفحة Filament (`content.manage`): اسم المبادرة، الشعار (فاتح وداكن)، الأيقونة.
2. لونان للهوية **من لوحة ألوان مضبوطة** مع فحص تباين WCAG AA على الخلفيتين الفاتحة والداكنة؛ يُرفض غير المقروء.
3. رفع الصور: تحقق فعلي من النوع، إعادة ترميز، حد للحجم، وتُخدم من نطاق الموقع.
4. حقن اللون كمتغيرات CSS (`--pri`, `--brass`) في التخطيط، مع كاش يُبطل عند التعديل.
5. كل تعديل → `audit_logs`.

## معايير القبول
- [ ] لا يمكن حفظ ألوان ضعيفة التباين.
- [ ] الشعار يظهر في الترويسة والتذييل وصفحات الإدارة.
- [ ] الوضع الداكن سليم.

## الاختبارات المطلوبة
- حساب التباين وحالاته.
- ملف غير صالح يُرفض.
- 403.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
