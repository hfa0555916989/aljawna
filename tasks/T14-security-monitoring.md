# T14 — الأمان والمراقبة وسجل التدقيق

- **الفرع:** `task/T14-security-monitoring`
- **يعتمد على:** T03, T02
- **المراجع:** `docs/SPEC.md` §12.7, FR-22, FR-23

## الهدف
تبويب الأمان، والحسابات المشبوهة، وتعطيل الحساب، وسجل تدقيق للإضافة فقط.

## المطلوب
1. تحصين `audit_logs` كجدول **للإضافة فقط**: مشغّل PostgreSQL يمنع UPDATE وDELETE، مع اختبار.
2. صفحة (`security.view`): سجل المحاولات، ومرشحات لسجل التدقيق.
3. قواعد الحسابات المشبوهة (عتبات في config): محاولات فاشلة كثيرة، تسجيلات كثيرة من IP واحد، طلبات استعادة متكررة.
4. إجراء تعطيل/تفعيل حساب مبادر (`users.suspend`) بسبب يُحفظ. الحساب المعطّل يُمنع من الدخول برسالة مناسبة.

## معايير القبول
- [ ] محاولة تعديل أو حذف سجل تدقيق تفشل على مستوى قاعدة البيانات.
- [ ] التعطيل يسري فورًا.

## الاختبارات المطلوبة
- اختبار المشغّل.
- قواعد الاشتباه.
- 403 للصفحة.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
