# T21 — النشر على Hostinger VPS والنسخ الاحتياطي

- **الفرع:** `task/T21-deploy-hostinger`
- **يعتمد على:** T20
- **المراجع:** `docs/SPEC.md` §11, §12.12

## الهدف
بيئة إنتاج آمنة على Hostinger KVM VPS، مع نشر آلي ونسخ احتياطي مجرَّب.

## المطلوب
1. **قبل الشراء:** سكربت/إجراء لقياس زمن الاستجابة من السعودية لكل موقع VPS متاح، وتوثيق النتيجة. تذكير: الموقع يثبت بعد الإعداد الأول.
2. تجهيز الخادم (موثَّق في `docs/RUNBOOK.md`): Ubuntu LTS، جدار ناري `ufw`، `fail2ban`، مستخدم غير جذر، مفاتيح SSH فقط، Nginx، PHP-FPM 8.3+، PostgreSQL، Redis، Supervisor لعامل الطوابير، Cron للمجدول، شهادة TLS.
3. GitHub Actions للنشر عند الدمج/الوسم: SSH، مجلدات إصدارات (release directories)، `composer install --no-dev`، بناء الأصول، `migrate --force`، تسخين الكاش، إعادة تحميل الخدمات، وسكربت **تراجع**.
4. النسخ الاحتياطي: `pg_dump` ليليًا + ملفات الإيصالات، **مشفّرة قبل الإرسال**، بسياسة احتفاظ (14 يومًا / 8 أسابيع / 6 أشهر)، ومكان خارج الخادم. **تجربة استرجاع** موثَّقة.
5. Cloudflare: DNS وحماية DDoS، ووضع SSL بمستوى Full (strict).
6. مراقبة: فحص توافر وتنبيهات قرص وأخطاء **بلا بيانات شخصية**.
7. قسم "الانتقال إلى خادم داخل المملكة" في `docs/RUNBOOK.md`: الخطوات لنقل النظام بتغيير الإعدادات فقط.

## معايير القبول
- [ ] نشر تجريبي على بيئة مرحلية ناجح، والتراجع يعمل.
- [ ] استرجاع نسخة احتياطية على خادم نظيف ناجح.
- [ ] لا أسرار في المستودع أو في سجلات CI.

## الاختبارات المطلوبة
- اختبار دخان بعد النشر (`/up` وصفحة رئيسية وتسجيل دخول).

## خارج النطاق
