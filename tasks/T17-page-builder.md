# T17 — منشئ الصفحات بالسحب والإفلات

- **الفرع:** `task/T17-page-builder`
- **يعتمد على:** T16
- **المراجع:** `docs/SPEC.md` FR-50..54, §12.13, §9

## الهدف
منشئ صفحات (Builder) بكتل منظّمة، مع القوائم والمعاينة والنسخ والضوابط.

## المطلوب
1. جداول `pages` و`page_revisions` و`menu_items` كما في §9.
2. حقل Builder في Filament (`content.manage`) بالكتل: عنوان رئيسي، نص منسّق، صورة، بطاقات، خطوات، أسئلة شائعة، عدّادات، فاصل، **كتلة "المبادرات" النظامية** (تقرأ من قاعدة المستفيدين فقط)، وكتلة "اتصل بنا" (تُنفَّذ في T18).
3. **بلا HTML خام ولا سكربت ولا iframe ولا CSS حر.** النص المنسّق يُنظَّف بقائمة عناصر مسموحة، والروابط `http/https/tel/wa.me` فقط، والصور بإعادة ترميز.
4. **منع حفظ أي نص حر يحتوي نمط آيبان سعودي أو رقم حساب**، مع رسالة عربية توضح السبب.
5. مسودة/منشور، **معاينة قبل النشر**، وسجل نسخ مع استرجاع.
6. الصفحات النظامية (تسجيل، دخول، لوحة، استعادة، مستفيدون) **خارج المنشئ**، ومسارات محجوزة لا تُستعمل كـ slug (`admin`, `login`, `register`, `forgot-password`, `reset`, `beneficiaries`, `dashboard`, `my-transfers`, `join`, `contact`, `up`, وغيرها).
7. عرض `GET /{slug}` (آخر مسار)، وحقول SEO، وخريطة موقع.
8. القائمة الرئيسية والتذييل من `menu_items`.
9. حدود لعدد الكتل وحجم الصفحة، وكل تعديل → `audit_logs`.

## معايير القبول
- [ ] حمولات XSS كلها تُنظَّف أو تُرفض.
- [ ] حفظ آيبان أو رقم حساب في نص حر مرفوض.
- [ ] الاسترجاع يعيد النسخة السابقة.
- [ ] لا يمكن لصفحة أن تحجب مسارًا نظاميًا.

## الاختبارات المطلوبة
- حمولات XSS متعددة.
- نمط الآيبان ورقم الحساب في كل الكتل النصية.
- الـ slugs المحجوزة.
- المعاينة لا تنشر، والنشر يكتب نسخة.

## قبل الدمج
- `composer lint && composer analyse && composer test`
- وصف PR بالقالب: ما تم، ما لم يتم، أسئلة مفتوحة، ولقطات شاشة (جوال 360px + كمبيوتر 1280px) للواجهات.
- راجع "تعريف الإنجاز" في `AGENTS.md`.
